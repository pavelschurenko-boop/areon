YSYouScore — перевірка реєстраційних даних

Призначення: внутрішній інструмент для спеціалістів підтримки. Дозволяє швидко зробити запит до методу «Реєстраційні дані» (Registration data) API YouScore за кодом ЄДРПОУ юридичної особи / РНОКПП ФОП і побачити повний результат перевірки — як позитивний (компанія знайдена, дані актуальні), так і негативний (компанія не знайдена, ліквідована, у стані припинення, некоректний код тощо).

Дані беруться напряму з Єдиного державного реєстру (ЄДР) через офіційний API YouControl / YouScore.

Натисніть Enter або кнопку «Реєстраційні дані», щоб надіслати запит до YouScore API. «Податкові дані (ПДВ)» перевіряє статус платника ПДВ, «Ліцензії» показує наявні ліцензії контрагента.
